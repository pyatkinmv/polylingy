# Установка и обновление (Windows)

Версия 0.8.x alpha. Приложение ставится обычным установщиком Windows (`.msi`), прогресс и курсы лежат отдельно от программы и при обновлении не трогаются.

## Как получить установщик

Установщик собирается из исходников:

```powershell
./gradlew :app:releaseMsi
```

Файл появится в `app/build/release/`, например `Polylingy-0.8.0-alpha.msi` (около 80 МБ). Слово «alpha» только в имени файла и в приложении (маленький текст внизу списка курсов); внутри MSI версия — только числа, `0.8.0`.

## Установка

1. Дважды щёлкните по `.msi`: Next, Next, Finish.
2. Программа ставится для текущего пользователя (права администратора не нужны), в меню «Пуск» появляется папка Polylingy с ярлыком.
3. При первом запуске приложение создаёт базу и сразу добавляет курс **English Usage Exercises** (около 2 секунд).

## Обновление на новую версию

1. Соберите (или получите) новый `.msi` — версия в нём должна быть выше.
2. Закройте Polylingy и запустите новый `.msi` поверх старого. Удалять старую версию не нужно: Windows узнаёт программу по неизменяемому идентификатору (`upgradeUuid`) и заменяет её.
3. Запустите приложение. База, журнал ответов и курсы остаются как были; если схема базы изменилась, перед этим делается копия `backups/polylingy-<дата>-before-schema-<n>.db`.
4. Если в новом установщике версия курса English Usage выше, чем у вас (`version`), курс обновится сам, **прогресс сохранится** у всех топиков, которые остались в курсе.

Проверка новых версий через интернет и автоматическое обновление пока не сделаны (итерация 2 и позже, см. `roadmap.md`).

## Где лежат данные

| Что | Где |
|---|---|
| База, картинки, логи, копии | `%LOCALAPPDATA%\Polylingy data` (обычно `C:\Users\<вы>\AppData\Local\Polylingy data`; сама программа стоит рядом, в `Polylingy`, и при обновлении заменяется, а `Polylingy data` — нет) |
| Вторая копия резервных баз | `Документы\Polylingy backups` (последние 14 дней; облако, например OneDrive, их сохранит) |
| Логи | `...\Polylingy data\logs\polylingy.log`, файл на день, 14 дней. При ошибке в окне есть кнопка «Open log folder» |

Данные не лежат в «Документах» намеренно: OneDrive синхронизирует их по файлам, а работающая база данных так повреждается. Резервные копии, наоборот, — статичные файлы, и облако для них хорошо подходит.

Запуск из исходников (`./gradlew :app:run`, IDE, тесты) использует **другую** папку, `Документы\polylingy`, поэтому разработка и установленное приложение не мешают друг другу.

## Резервные копии

- При каждом первом запуске за день создаётся `backups\polylingy-<дата>.db`, хранятся последние 14.
- Перед миграцией базы после обновления — `backups\polylingy-<дата>-before-schema-<n>.db`, последние 5.
- Копия — обычный файл базы. Восстановление: закрыть приложение, заменить `polylingy.db` файлом копии (переименовав его в `polylingy.db`).

## Перенос на другой компьютер

1. Установите ту же или более новую версию на новом компьютере и один раз запустите её.
2. Закройте приложение на обоих компьютерах.
3. Скопируйте со старого `polylingy.db` (и, если есть, папку `images`) в папку данных нового, заменив файл.
4. Запустите приложение.

Синхронизации между компьютерами пока нет; одновременно работать с двумя копиями нельзя (прогресс не объединяется).

## Если что-то пошло не так

- Окно «Something went wrong» — приложение продолжает работать; детали в логе.
- Не открывается: удалите ярлык и установите `.msi` заново, данные останутся.
- Нужно вернуть данные на вчера: см. «Резервные копии».
